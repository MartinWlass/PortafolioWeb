Script Hook V

Script Hook V es la biblioteca que permite usar funciones nativas de scripts de GTAV en complementos *.asi personalizados. Ten en cuenta que no funciona en GTA Online; el script hook cierra GTA V cuando el jugador entra en multijugador. Consulta los detalles en el archivo Léame.

Esta distribución también incluye el último Asi Loader y Native Trainer .

Instalación

  1. Copia ScriptHookV.dd a la carpeta principal del juego, donde se encuentra GTA5.exe.
  2. Para cargar los plugins ASI, necesitas tener instalado el cargador ASI. Puedes descargarlo por separado o usar la última versión incluida con esta distribución (dinput8.dll). Debes eliminar la versión anterior del cargador ASI (dsound.dll) si la tienes instalada.
  3. Esta distribución también incluye un plugin ASI de ejemplo: Native Trainer. Si necesitas un entrenador, copia también NativeTrainer.asi.

Concepto

El concepto principal es que los complementos de script compilados dependen solo de ScriptHookV.dll, por lo que cuando el juego se actualiza lo único que el usuario debe hacer para que los script vuelvan a funcionar es actualizar el tiempo de ejecución del gancho de script (es decir, ScriptHookV.dll).
